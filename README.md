## 🔎 About the Game
‘미림에서 살아남기’는 게임 속 미림의 일상을 배경으로 일어나는 사건들을 
디버깅(오류 검출)을 통해 해결해나가는 코딩교육용 스토리형 게임입니다. <br/>
게임 속의 코딩으로 코딩에 대한 친밀도와 흥미를 높이고, 스토리 속 참여 디버깅을 통해 에러에 대한 공포를 극복하도록 하는것이 주목적입니다. <br/>
챕터1에서는 Java코드를 직접 수정하는 주관식 문제를, 챕터2에서는 다섯가지 선택지 중, 올바른 Python코드를 선택하는 객관식 문제를 풀 수 있습니다.
